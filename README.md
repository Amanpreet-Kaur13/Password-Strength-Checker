# Password Strength Checker 🔐

A simple Python project that checks password strength based on different conditions.

## Features

- Checks for uppercase letters
- Checks for lowercase letters
- Checks for numeric digits
- Checks for special characters
- Checks whether the password is at least 8 characters long
- Calculates a score based on the conditions
- Displays the result as Strong, Medium, or Weak

## Technologies Used

- Python

## How It Works

The program checks five conditions:

1. Uppercase letter
2. Lowercase letter
3. Digit
4. Special character
5. Minimum length of 8 characters

Each satisfied condition adds 1 point to the score.

## Password Strength Levels

- Strong: Score = 5
- Medium: Score = 3 or 4
- Weak: Score = 0, 1, or 2

## How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Run the following command:

python password_strength_checker.py

## Project Description

This is a beginner-level Python project created to practice loops, conditional statements, string methods, Boolean variables, and score calculation.
